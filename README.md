# linux-config

My Hyprland setup on Arch. The repo *is* `~/.config` — `.gitignore` ignores
everything by default and I allowlist directories as I go, so only configs I
actually wrote are in here.

Compositor is Hyprland (Lua config), and the bar/launcher/notifications all come
from DankMaterialShell (`dms-shell`) running on quickshell. Login is greetd with
the DMS greeter, terminal is ghostty, editor is neovim (LazyVim), shell is zsh
+ starship. Colours are generated from the wallpaper with matugen and pywal —
pick an image and everything follows.

Plasma is installed but unused; ignore the KDE files.

## Setting it up on a new machine

Check the repo out over `~/.config` in place so existing untracked files survive:

```sh
cd ~/.config
git init
git remote add origin https://github.com/vesab0/linux-config
git fetch origin
git checkout -f -b main origin/main
```

Then run `./install.sh`. It installs paru and the package lists, oh-my-zsh, links
`home/.zshrc` and `home/.bashrc` into `$HOME`, copies the dms-shell overrides into
`/usr/share/quickshell/dms/`, enables the services, and offers to swap sddm for
greetd. Afterwards run `gh auth login` (my gitconfig expects the credential
helper), drop a wallpaper in `~/Pictures/wallpapers`, pick it with
`hypr/wallpaper.sh`, and reboot.

## If you're not on my desktop

Four files hard-code my three monitors. Check yours with `hyprctl monitors` —
laptops are usually just `eDP-1`.

- `hypr/dms/outputs.lua` — swap the `DP-2`/`DP-3`/`HDMI-A-1` entries for one
  `hl.monitor({ output = "eDP-1", mode = "preferred", position = "0x0", scale = 1 })`.
  Leave the empty-output fallback for external displays.
- `hypr/hyprland.lua` — workspaces 1–5 are pinned to `DP-2` and 6–10 to `DP-3`;
  collapse that to one loop over 1–10 with no `monitor` field. The autostart block
  also throws neofetch/cmatrix/cava on workspace 10 and vesktop/spotify on 1.
- `hypr/dms/binds-user.lua` — `focus_workspace_on_monitor` special-cases `DP-2`.
  On one screen just delete it and let the default `SUPER+I`/`SUPER+K` binds work.
- `hypr/monitors.conf` / `.json` — generated by `hyprmon`, so re-run that instead
  of editing by hand.

On a laptop you'll also want `power-profiles-daemon` and battery-aware idle
timeouts (`hypr/hypridle.conf` only has AC ones), plus whatever GPU driver and
microcode you need — `packages/skip.txt` lists the NVIDIA/lact/intel-ucode bits
the installer deliberately leaves out.

## What's tracked

`hypr/`, `quickshell/`, `waybar/`, `eww/`, `wofi/`, `rofi/`, `dunst/`, `swaync/`,
`kitty/`, `nvim/`, `gtk-3.0/`, `gtk-4.0/`, `xsettingsd/`, `starship.toml`,
`mimeapps.list`, `user-dirs.dirs`, and:

- `DankMaterialShell/settings.json` — the whole DMS config (bar, widgets, theme,
  lock screen). The rest of that directory is app state and stays ignored.
- `packages/` — `pacman.txt` and `aur.txt`. Refresh with
  `pacman -Qqen > packages/pacman.txt` and `pacman -Qqem > packages/aur.txt`.
- `home/` — `.zshrc` and `.bashrc`, symlinked in by the installer since the repo
  root is `~/.config` and can't hold them where they belong.
- `system/greetd-config.toml` — goes to `/etc/greetd/config.toml`.

The generated colour files that are tracked (`gtk-3.0/dank-colors.css`,
`gtk-4.0/dank-colors.css`, `kitty/current-theme.conf`) get overwritten as soon as
you pick a wallpaper, so don't read anything into them.

## dms-shell overrides

`quickshell/dms-overrides/` holds patched copies of files from the `dms-shell`
package that add a Notes (kanban) tab to the DankDash popout. Package upgrades
silently clobber them, so re-run `install.sh` after every `dms-shell` update.
