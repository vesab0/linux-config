# linux-config

Hyprland dotfiles for Arch Linux, built on top of the DankMaterialShell (DMS) shell.

The repository **is** `~/.config`. Everything is opt-in via `.gitignore`: files are
ignored by default and allowlisted one directory at a time.

## What this setup is

| Piece | Package |
| --- | --- |
| Compositor | `hyprland` (Lua config — `hypr/hyprland.lua`) |
| Shell / bar / launcher | `dms-shell` (quickshell), configured by `DankMaterialShell/settings.json` |
| Login manager | `greetd` + `greetd-dms-greeter-bin` |
| Terminal | `ghostty`, `kitty` |
| Theming | `matugen` + `python-pywal`, wallpaper via `awww` |
| Editor | `neovim` (LazyVim) |
| Shell | `zsh` + oh-my-zsh + `starship` |

KDE/Plasma packages are installed too, but the daily driver is Hyprland — Plasma is
not what these configs drive.

## Reproducing this on a new machine

1. **Install Arch** with a normal user, `git`, `base-devel` and a working network.

2. **Check the repo out over `~/.config` in place.** This keeps files that already
   exist there and are not tracked:

   ```sh
   cd ~/.config
   git init
   git remote add origin https://github.com/vesab0/linux-config
   git fetch origin
   git checkout -f -b main origin/main
   ```

3. **Run the bootstrap:**

   ```sh
   ~/.config/install.sh
   ```

   It installs `paru`, the package lists under `packages/`, oh-my-zsh, links
   `home/.zshrc` and `home/.bashrc` into `$HOME`, copies the `dms-shell` overrides
   into `/usr/share/quickshell/dms/`, enables the user/system services, and
   (after asking) swaps the login manager to greetd.

4. **Adjust for the machine's displays** — see below — then reboot.

5. Drop at least one image in `~/Pictures/wallpapers` and pick it with
   `hypr/wallpaper.sh`; the whole colour scheme is generated from it.

`gh auth login` restores the GitHub credential helper that `~/.gitconfig` expects.

## Laptop / new machine: what must be edited

Four tracked files hard-code this desktop's three monitors. On a laptop the
internal panel is usually `eDP-1` — check with `hyprctl monitors`.

- **`hypr/dms/outputs.lua`** — replace the `DP-2` / `DP-3` / `HDMI-A-1` entries
  with a single `hl.monitor({ output = "eDP-1", mode = "preferred", position = "0x0", scale = 1 })`.
  Keep the empty-output fallback line for external displays.

- **`hypr/hyprland.lua`** — the workspace loops pin workspaces 1–5 to `DP-2` and
  6–10 to `DP-3`. On one screen, collapse them to a single loop over 1–10 with no
  `monitor` field. The autostart block also opens neofetch/cmatrix/cava on
  workspace 10 and vesktop/spotify on workspace 1; trim to taste.

- **`hypr/dms/binds-user.lua`** — `focus_workspace_on_monitor` branches on the
  monitor being named `DP-2`. With one monitor, delete the helper and let the
  default `SUPER+I`/`SUPER+K` binds stand.

- **`hypr/monitors.conf` / `hypr/monitors.json`** — generated by `hyprmon`; just
  re-run it on the laptop rather than hand-editing.

Also worth doing on a laptop:

- `packages/skip.txt` lists the NVIDIA, `lact`, `intel-ucode` and `piper` packages
  the installer leaves out. Add `amd-ucode` for AMD, or the right GPU driver.
- Install `power-profiles-daemon` and enable battery-aware idle timeouts —
  `hypr/hypridle.conf` currently has one set of AC timeouts.
- `hypr/hyprland.lua` sets `touchpad.natural_scroll = true` and `tap_to_click = true`
  already.

## What is tracked, and what is not

Tracked: `hypr/`, `quickshell/`, `waybar/`, `eww/`, `wofi/`, `rofi/`, `dunst/`,
`swaync/`, `kitty/`, `nvim/`, `gtk-3.0/`, `gtk-4.0/`, `xsettingsd/`,
`starship.toml`, `mimeapps.list`, `user-dirs.dirs`, plus:

- `DankMaterialShell/settings.json` — the DMS shell configuration (bar layout,
  widgets, theme, lock screen). The rest of that directory is app state and stays
  ignored.
- `packages/` — `pacman.txt` and `aur.txt`, snapshots of the explicitly installed
  packages. Regenerate with `pacman -Qqen > packages/pacman.txt` and
  `pacman -Qqem > packages/aur.txt`.
- `home/` — `.zshrc` and `.bashrc`, symlinked into `$HOME` by the installer, since
  the repo root is `~/.config` and cannot hold them in place.
- `system/greetd-config.toml` — copied to `/etc/greetd/config.toml`.

The DMS plugins are separate upstream repos and are not vendored here. Clone them
into `~/.config/DankMaterialShell/plugins/`:

| Plugin | Repo |
| --- | --- |
| `cavaVisualizer` | https://github.com/ernestowgg/cava-visualizer |
| `githubHeatmapPlus` | https://github.com/maxlen727/DMS-GitHub_HeatMap_Plus |
| `pureLyrics` | https://github.com/lildengzi/pureLyrics |

Not tracked, and re-created on first run: `~/.cache/wal/` (pywal output) and
everything else under `DankMaterialShell/`. The generated colour files that *are*
tracked (`gtk-3.0/dank-colors.css`, `gtk-4.0/dank-colors.css`,
`kitty/current-theme.conf`) get overwritten the first time you pick a wallpaper.

## dms-shell overrides

`quickshell/dms-overrides/` holds hand-patched copies of files from the `dms-shell`
package, which adds a Notes (kanban) tab to the DankDash popout. Package updates
overwrite them without warning — re-run `install.sh`, or see that directory's
README, after every `dms-shell` upgrade.
